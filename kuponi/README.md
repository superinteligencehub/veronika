# Kuponi LV — купоны и скидки Латвии в одном приложении

PWA, которое каждый день автоматически собирает акции магазинов Латвии и показывает их
**по-русски**, отсортированными по реальной выгоде в евро.

- **Приложение:** `https://superinteligencehub.github.io/veronika/kuponi/web/` (после включения GitHub Pages, см. ниже)
- **Данные:** `kuponi/data/coupons.json` — обновляет GitHub Actions раз в сутки
- **Без платных сервисов и без ключей в клиенте.**

## Что умеет (MVP)

| Функция | Где |
|---|---|
| Лента купонов: магазин, товар (LV + перевод RU), старая/новая цена, −€ и −%, срок, условия, ссылка | «Лента» |
| Фильтры: категория, магазины, «сегодня последний день», мин. скидка %/€, без карты/приложения, мои магазины | «Лента» → «Фильтры» |
| «Лучшее сегодня» — топ-30 по выгоде в €, отдельно «заканчиваются сегодня» | «Лучшее» |
| Поиск по-русски («молоко», «кофе», «масло для двигателя») + таблица «где дешевле» по цене за кг/л/шт | «Поиск» |
| Избранное и «мои магазины» | «Избранное» |
| Утреннее уведомление 08:00 (Рига): топ-5 + что истекает сегодня | «Ещё» → Уведомления |
| Статус каждого источника (работает / старые данные / ошибка / ручной ввод / в планах) | «Ещё» → Источники |
| Ручной ввод купона, в т.ч. по фото/скриншоту (распознавание текста в браузере) | «Ещё» → Добавить купон |
| Офлайн-режим с последними данными, установка на Android, тёмная/светлая тема | везде |

## План и источники

Оценка сделана по проверке сайтов 02.11.2026: только публичные страницы, без логинов,
капч и обхода защит. Если сайт отвечает проверкой бота — источник помечается **«ручной ввод»**.

### Этап 1 — MVP (сделано)

| Источник | Режим | Что собирается |
|---|---|---|
| **Rimi** | ✅ авто | Раздел акций e-veikals (~4000 товаров, ~600–700 со скидкой): цена, обычная цена, цена за кг/л. Срок акции — со страницы товара для топ-150 по выгоде (у остальных «срок уточняйте»). Цены интернет-магазина. |
| **Maxima** | ✅ авто | Все ~950 акций (тот же AJAX, что кнопка «Rādīt vairāk»): цена с картой PALDIES / в приложении, обычная цена или %, срок, условия. |
| **Lidl** | ✅ авто | Страницы «Aktuālie piedāvājumi», «Lidl TOP preces», «Super brīvdienas» (~40–60 товаров): цена, старая цена, %, цена Lidl Plus, даты. Купоны Lidl Plus — только в приложении. |
| **Circle K** | ✅ авто | Спецпредложения (текст + цена, если указана) и официальные цены на топливо. Персональные купоны EXTRA — только в приложении. |
| **McDonald's** | ✍️ ручной | Сайт закрыт проверкой Cloudflare, купоны — в приложении. Скрапер лишь проверяет, не открылся ли сайт. |

### Этап 2 — масштабирование (следующие источники)

| Категория | Авто (вероятно) | Частично (PDF/новости) | Ручной ввод |
|---|---|---|---|
| Продукты | Barbora | Mego, top!, Elvi | — |
| Фастфуд/кафе | KFC, Burger King | Lido | Double Coffee, купоны McDonald's/KFC/BK в приложениях |
| Авто | Neste, Virši, Viada (цены на топливо и акции) | — | автомойки/шины — по мере нахождения публичных страниц |
| Электроника/дом | Depo | Elkor (нужна доп. проверка) | 1a.lv, Pigu (HTTP 403) |
| Красота/аптеки | Apotheka, Benu | — | Drogas (HTTP 403) |
| Спорт/досуг/доставка | Sportland | Forum Cinemas | Apollo Kino (403), Wolt, Bolt Food (только приложение/аккаунт) |
| Агрегаторы | Salidzini.lv (для сравнения цен) | — | Kurpirkt.lv (403) |

Каждый новый источник = один файл `scrapers/stores/<id>.js` + строка в `scrapers/sources.js`
(режим `planned` → `auto`) + тест на фрагменте страницы.

### Этап 3 — улучшения

- категории товаров внутри «Продуктов» (молочное, мясо, напитки…);
- сравнение одинаковых товаров между магазинами по штрихкоду/названию;
- история цен («реальная ли скидка» — сравнение с ценой месяц назад).

## Как это устроено

```
kuponi/
  scrapers/
    sources.js          реестр всех источников (auto / planned / manual + оценка)
    run.js              оркестратор: изоляция ошибок, нормализация, дедупликация, срок, перевод
    stores/*.js         по одному модулю на магазин
    lib/                http (честный User-Agent, паузы, детект проверки бота), формат купона, перевод
    notify-ntfy.js      резервное утреннее уведомление через ntfy.sh
  data/
    coupons.json        результат сбора (+ статусы источников)
    translations.json   кэш переводов LV→RU
    manual.json         купоны, добавленные вручную в репозитории
  web/                  PWA (без сборки, чистый JS): index.html, app.js, sw.js, glossary.js…
  worker/               Cloudflare Worker для Web Push (бесплатный тариф)
  tests/                тесты парсеров на фрагментах реальных страниц
.github/workflows/
  kuponi-scrape.yml     ежедневный сбор 05:17/06:17 по Риге + коммит данных
  kuponi-morning.yml    уведомление в ntfy в 08:00 (если задана переменная NTFY_TOPIC)
```

**Общий формат купона** описан в `scrapers/lib/normalize.js` (id, source, store, category, kind,
title, titleRu, priceNew, priceOld, savingEur, savingPct, unitPrice, validFrom, validTo,
conditions, conditionsRu, requires, url, image, firstSeen).

**Надёжность.** Каждый скрапер выполняется изолированно с таймаутом. Если источник упал,
остальные продолжают работать, а в приложении источник получает статус «старые данные»
(показываются его прошлые, ещё не истёкшие купоны) или «ошибка». Просроченные купоны
(`validTo` < сегодня по Риге) отбрасываются и при сборе, и в приложении.

**Перевод.** При сборе (не в браузере): кэш → бесплатный онлайн-перевод без ключей
(Google `translate_a`, запасной MyMemory) → словарь `web/glossary.js`. Словарные «черновые»
переводы при следующем сборе снова отправляются в онлайн-перевод. Тот же словарь даёт
поиск по-русски по латышским названиям.

## Запуск и включение

```bash
cd kuponi
npm ci
npm test                 # тесты парсеров
npm run scrape           # полный сбор (~4 минуты) → data/coupons.json
npm run serve            # http://localhost:8080/web/
```

1. **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.
   Приложение откроется по адресу `…github.io/veronika/kuponi/web/`.
2. **Автообновление:** workflow `kuponi-scrape.yml` запускается по расписанию на ветке по
   умолчанию (после слияния в `main`). Ручной запуск: Actions → «Kuponi LV — сбор купонов» → Run.
   Нужны права: Settings → Actions → General → Workflow permissions → *Read and write*.
3. **Установка на Android:** открыть приложение в Chrome → меню → «Установить приложение».
4. **Уведомления в 08:00** — один из вариантов:
   - **Web Push (рекомендуется):** развернуть бесплатный Worker — инструкция в [`worker/README.md`](worker/README.md);
   - **ntfy (без сервера):** установить приложение ntfy, подписаться на свою (случайную) тему,
     создать переменную репозитория `NTFY_TOPIC` (и `KUPONI_APP_URL` — адрес приложения);
   - **без сервера вообще:** «Ещё» → «Показывать утренний дайджест при фоновом обновлении»
     (Chrome сам выбирает время фонового обновления, поэтому 08:00 не гарантируется).

## Ручные купоны

- В приложении: «Ещё» → «Добавить купон» (можно по фото — текст и цены распознаются
  Tesseract.js прямо в браузере). Такие купоны хранятся на телефоне.
- Чтобы купон был виден всем и попал в уведомления — «Экспорт для data/manual.json»,
  вставить в `kuponi/data/manual.json` на GitHub. Формат — как у купона
  (`store`, `title`, `priceNew`, `priceOld`, `validTo`, `conditions`, `url`…).

## Правила сбора

- Только публичные страницы/JSON, которые сайт отдаёт любому посетителю; `robots.txt` проверен.
- Честный User-Agent `KuponiLV/1.0 (+ссылка на репозиторий)`, пауза между запросами, 1 сбор в сутки.
- Логины, капчи, проверки ботов и закрытые API не обходятся — такие источники = ручной ввод.
- Цены и условия могут отличаться в конкретном магазине; в карточке всегда есть ссылка на источник.
